Ashveil Engine Python SDK

Integrate autonomous animation generation directly into narrative production pipelines. Pass unstructured raw chapters, novels, or screenplays, and receive synchronized 4K animation sequences.

Private Alpha Rate Limits: Public API keys are rate-limited to 50 concurrent inferences. For production studio clusters or air-gapped on-premise instances, contact developer relations.

Install the official Ashveil Python client library via standard package distribution:

TERMINALbash
pip install ashveil-engine

2. Autonomous Novel-to-Anime Execution

Example script analyzing a serialized chapter, extracting character canonical embeddings, and generating a 60fps cinematic cut:

director_pipeline.pypython
import ashveil

# Initialize Cognitive Director client
client = ashveil.Client(api_key="ash_alpha_live_9482bf1")

# Ingest raw novel chapter with Long-Context Foundation LLM
print("Parsing manuscript logic & character bible...")
storyboard = client.director.ingest_manuscript(
    source_file="chapter_14_the_ashen_throne.txt",
    format="royal_road",
    long_context_window="200k",
    style_preset="dark_fantasy_60fps"
)

# Trigger Autonomous Multi-Agent validation & 4K render
print(f"Compiled {len(storyboard.shots)} cinematic shots. Initiating render cluster...")
render_job = client.render.dispatch(
    storyboard_id=storyboard.id,
    resolution="4K_UHD",
    frame_rate=60,
    temporal_consistency_lock=True
)

print(f"Sequence ready: {render_job.stream_url}")

3. Manuscript Format Compatibility

The ingestion parser natively recognizes structure formats from major creative serialization repositories:

  • Royal Road & Webnovel: Ingests chapter-by-chapter progression, preserving author commentary notes and system popups.
  • Final Draft (.fdx) & Fountain: Converts standard sluglines, action paragraphs, and parentheticals directly into camera shot vectors.
